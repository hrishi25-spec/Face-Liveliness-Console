# Security Policy

Please report security vulnerabilities privately through this repository's GitHub
**Security → Report a vulnerability** advisory form, not in a public issue. Include
the affected route or component and a reproduction that uses synthetic data only —
never a real face, biometric sample, credential or production identifier.

The service has no bug-bounty programme, and an acknowledgement does not make an
issue eligible for one. See `docs/design.md` §6 for the threat model and the
injection-attack residual risk, and `docs/acceptance-audit.md` for known gaps.
